faildex · built on Relate

Coding agents fail the same way twice. The graph remembers.

faildex reads Claude Code, Codex and Cursor logs into one Relate graph, finds the failures that keep coming back, and warns the agent before it repeats one. This page rebuilds that graph from 422 public sessions in your browser and runs every query live. Nothing is sent to a server.

Ask before you run
The same lookup the Claude Code hook and the MCP preflight tool make. A command with a recurring failure gets one line of warning; every other command gets silence.

How much was already known
Sessions of each dataset are ordered by start time: the first 70% are earlier, the rest later. A later failure is recurring when an earlier session already hit it, and warnable when an earlier session also shows the same command working again within five calls.
